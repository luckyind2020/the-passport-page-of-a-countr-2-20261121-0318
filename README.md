A Python program (stdlib only, no network) that draws an invented passport
spread for the Republic of Auralia, an archipelago that does not exist: a
data page with a portrait, personal details and a machine-readable zone
whose check digits are computed for real, plus a visa page with a Norvane
visitor visa, six entry/exit stamps from three neighbouring countries, a
tide-fee stamp, and one telling condition of stay — the holder may not
enter the Northern Reef Zone without a tide permit. Every date agrees:
issued 14 MAR 2023, all stamps fall after issue in chronological order,
and the Norvane entry and exit stamps sit inside the visa's validity.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes `/output/entry.png` by default (1024x1024 PNG, about 27 KB,
deterministic: byte-identical on every run).
